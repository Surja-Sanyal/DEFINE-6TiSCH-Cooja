Set Up an Auto-Push Alias:
If you want a single command to commit and push everything instantly before you leave, you can create a Git alias by running this once in your terminal:

git config --global alias.save '!git add -A && git commit -m "Auto-save simulation progress" && git push'

Then, whenever you want to sync your work to GitHub, you just type:

git save
